FlatTileBuffer

ldtk.rules.FlatTileBuffer (Class)
Implements: AutoTileSink

Flat, reusable tile buffer for runtime use: STRIDE ints per tile, no object per tile. Layout per tile: ruleUid, coordId, tid, flips, x, y, srcX, srcY, alpha*4096. Tiles are stored rule by rule, in the order they were produced; segment* accessors give the range of each rule. The buffer keeps its capacity between reset() calls.
