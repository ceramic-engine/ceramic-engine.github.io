ceramic.PixelArtPreset (Class)

A complete set of PixelArt settings, as data: every property of the filter, with the defaults of the filter itself. Apply one with PixelArt.applyPreset(), read the current settings back with PixelArt.toPreset(), and paste the result of toHaxe() in code to keep a look that was tuned at runtime.

Built-in presets: sharp, clean, crtTv, crtMonitor, gba, lite (see byName()).
