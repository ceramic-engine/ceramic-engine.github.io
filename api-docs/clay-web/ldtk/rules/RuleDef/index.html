RuleDef

ldtk.rules.RuleDef (Class)

All the data of an auto-layer rule needed to compute tiles, plus the pure pattern helpers. The LDtk editor extends this class; other consumers (games, tools) build instances with fromJson. Pattern cell encoding: see RuleConst.
