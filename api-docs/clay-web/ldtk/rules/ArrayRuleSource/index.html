ArrayRuleSource

ldtk.rules.ArrayRuleSource (Class)
Implements: RuleSource

RuleSource over a flat IntGrid array (same layout as the intGridCsv JSON field: row major, 0 = empty). Keeps per-area value counters so that the engine prefilter can skip irrelevant rules, exactly like the LDtk editor does. IntGrid groups are counted under their rule value (groupUid+1)*1000.
