RuleEngine

ldtk.rules.RuleEngine (Class)

The auto-layer rule engine: matches rule patterns against a RuleSource IntGrid and produces tiles for a RuleTarget layer. One engine per target layer instance, reusable. Hot paths never allocate.

Two output paths share the same matching and tile production code:

  • the editor path works on an AutoTileCache map (per rule, per cell), supports partial recomputes (applyRulesInRect) and applies break-on-match as a final pass;
  • the runtime path writes into a reusable buffer and applies break-on-match on the fly: computeAll fills a FlatTileBuffer, computeFull and computeRect fill a CellTileBuffer which supports partial recomputes. All produce the same tiles.

computeRect(store: CellTileBuffer, rulesEvalOrder: Array<RuleDef>, cx: Int, cy: Int, wid: Int, hei: Int): Int#

Recompute the tiles of a rectangle of cells in a store previously filled by computeFull (or computeRect), after the source IntGrid changed in that rectangle. The area is expanded by MAX_RADIUS so that every pattern reading a modified cell is re-evaluated; break-on-match locks are reset and recomputed for these cells only. The result is identical to a full recompute. Falls back to computeFull if the store does not match the layer or if the rule list changed. Returns the number of recomputed cells.
