RulePerlin

ldtk.rules.RulePerlin (Class)

2D Perlin noise, ported from hxd.Perlin of the Heaps engine (MIT license, Copyright (c) 2013 Nicolas Cannasse). Only the parts used by the LDtk rule engine are kept. The integer index hash uses 32 bit arithmetic so that every target produces the same values; the rest is plain IEEE double arithmetic.
