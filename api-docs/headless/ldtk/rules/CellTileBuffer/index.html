CellTileBuffer

ldtk.rules.CellTileBuffer (Class)
Implements: AutoTileSink

Cell indexed tile store for runtime use, supporting partial recomputes: the tiles of any cell can be cleared and rewritten in place (RuleEngine.computeRect). Records live in a reusable pool of STRIDE ints, chained per cell; the capacity is kept between computes and nothing is allocated once the pool has reached its peak size. Record layout: ruleIndex (index in the evaluation order), tid, flips, x, y, srcX, srcY, alpha*4096, next record (-1 = end).

writeDisplayOrder(out: Array<Int>): Int#

Write every tile in display order (rules from the last evaluated to the first, cells in ascending order, tiles of a cell in production order) as 7 ints per tile: tid, flips, x, y, srcX, srcY, alpha*4096. This is the autoLayerTiles layout and the exact order produced by RuleEngine.flatten in the editor. out is reused and resized; returns the number of ints written.
